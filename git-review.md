Staging area: là nơi chuẩn bị cho các commit tiếp theo
Commit khác push: Commit là tạo snapshot từ nội dung đã stage, còn Push là gửi các commit local đến nhánh ở Github
Fetch là tải commit mới từ Github về máy và cập nhật vào origin/master nhưng chưa làm thay đổi master hay file đang làm việc. Pull là fetch rồi thay đổi nội dung nhánh đang làm việc
